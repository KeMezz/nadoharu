## ADDED Requirements

### Requirement: 게시물 작성/수정 폼은 핵심 입력 필드와 검증을 제공해야 한다

시스템은 게시물 작성/수정 폼에서 본문 텍스트, 보조 텍스트(subcontent), 이미지 입력(최대 4장)을 제공해야 한다(MUST). 최소 콘텐츠는 trim된 `content` 또는 1개 이상의 `imageUrls`로 정의해야 하며(MUST), `subcontent`는 선택 입력으로 처리해야 한다(MUST). 유효하지 않은 입력 상태에서는 제출을 차단하고 검증 메시지를 노출해야 한다(MUST).

#### Scenario: 필수 입력 누락 상태에서 제출 시도

- **WHEN** 사용자가 trim 기준 빈 `content`와 빈 `imageUrls` 상태(예: `subcontent`만 입력)로 작성/수정 제출을 시도한다
- **THEN** 시스템은 제출을 차단하고 검증 오류를 표시한다

#### Scenario: 유효한 입력으로 작성 제출

- **WHEN** 사용자가 유효한 입력값으로 게시물 작성을 제출한다
- **THEN** 시스템은 생성 요청을 전송한다

### Requirement: 카테고리 입력은 이번 범위에서 비활성화되어야 한다

시스템은 게시물 작성/수정 화면에서 카테고리 입력 UI를 노출하지 않아야 한다(MUST). 시스템은 게시물 작성/수정 요청의 카테고리 값을 빈 값으로 고정해야 한다(MUST).

#### Scenario: 작성/수정 폼에서 카테고리 입력 미노출

- **WHEN** 사용자가 게시물 작성 또는 수정 폼을 연다
- **THEN** 시스템은 카테고리 입력 컨트롤을 표시하지 않는다

#### Scenario: 작성/수정 제출 시 카테고리 빈 값 고정

- **WHEN** 사용자가 게시물 작성 또는 수정을 제출한다
- **THEN** 시스템은 카테고리를 빈 값으로 설정해 요청한다

### Requirement: 게시물 작성/수정 제출 상태를 사용자에게 명확히 표시해야 한다

시스템은 작성/수정 제출 과정에서 로딩, 성공, 실패 상태를 명확히 표시해야 한다(MUST). 성공 시 사용자가 결과를 확인할 수 있는 화면으로 이동시켜야 한다(MUST).

#### Scenario: 제출 중 로딩 상태 표시

- **WHEN** 사용자가 작성/수정 제출 버튼을 누른다
- **THEN** 시스템은 중복 제출을 막고 로딩 상태를 표시한다

#### Scenario: 작성 제출 성공 처리

- **WHEN** 작성 요청이 성공해 생성된 게시물 ID가 반환된다
- **THEN** 시스템은 성공 상태를 반영하고 `/posts/[id]`(생성된 ID) 상세 화면으로 이동한다

#### Scenario: 수정 제출 성공 처리

- **WHEN** 수정 요청이 성공한다
- **THEN** 시스템은 성공 상태를 반영하고 수정한 게시물의 `/posts/[id]` 상세 화면으로 이동한다

#### Scenario: 제출 실패 처리

- **WHEN** 작성/수정 요청이 실패한다
- **THEN** 시스템은 실패 메시지와 재시도 가능한 상태를 표시한다

### Requirement: 게시물 작성/수정 실패는 GraphQL 인증/인가 코드를 구분해 표시해야 한다

시스템은 게시물 작성/수정 요청 실패 시 GraphQL `errors[].extensions.code`를 기준으로 인증 실패와 권한 부족을 구분해 안내해야 한다(MUST). 작성 요청의 인증 실패는 `UNAUTHENTICATED`(또는 401 의미 코드)로 해석해야 하며(MUST), 수정 요청의 인증 실패/권한 부족은 `UNAUTHENTICATED`/`FORBIDDEN`(또는 401/403 의미 코드)으로 해석해야 한다(MUST). 인증 실패 시 재인증 동작을, 권한 부족 시 권한 없음 안내를 제공해야 한다(MUST).

#### Scenario: 작성 요청이 인증 오류 코드로 실패

- **WHEN** 사용자가 게시물 작성을 시도했지만 GraphQL `errors[].extensions.code`가 `UNAUTHENTICATED`(또는 401 의미 코드)다
- **THEN** 시스템은 로그인 필요 메시지와 로그인 이동 동작을 표시한다

#### Scenario: 수정 요청이 인증 오류 코드로 실패

- **WHEN** 사용자가 게시물 수정을 시도했지만 GraphQL `errors[].extensions.code`가 `UNAUTHENTICATED`(또는 401 의미 코드)다
- **THEN** 시스템은 로그인 필요 메시지와 로그인 이동 동작을 표시한다

#### Scenario: 수정 요청이 권한 오류 코드로 실패

- **WHEN** 사용자가 게시물 수정을 시도했지만 GraphQL `errors[].extensions.code`가 `FORBIDDEN`(또는 403 의미 코드)다
- **THEN** 시스템은 수정 권한 없음 메시지를 표시한다
