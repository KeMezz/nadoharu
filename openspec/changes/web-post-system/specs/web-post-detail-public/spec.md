## ADDED Requirements

### Requirement: `/posts/[id]` 단건 상세는 인증 여부와 무관하게 조회 가능해야 한다

시스템은 인증 사용자와 비인증 사용자 모두에게 `/posts/[id]` 게시물 상세 화면을 제공해야 한다(MUST). 공개 상세 조회는 인증 토큰 없이도 동작해야 한다(MUST).

#### Scenario: 비인증 사용자의 단건 상세 조회

- **WHEN** 비인증 사용자가 유효한 게시물 ID로 `/posts/[id]`에 접근한다
- **THEN** 시스템은 로그인 리다이렉트 없이 게시물 상세를 표시한다

#### Scenario: 인증 사용자의 단건 상세 조회

- **WHEN** 인증 사용자가 유효한 게시물 ID로 `/posts/[id]`에 접근한다
- **THEN** 시스템은 게시물 상세를 표시한다

### Requirement: 단건 상세는 게시물 식별자 오류에 대해 명확한 실패 상태를 제공해야 한다

시스템은 존재하지 않거나 접근할 수 없는 게시물 ID에 대해 실패 상태 UI를 제공해야 한다(MUST). 실패 상태에서는 사용자가 복구할 수 있는 동작(재시도 또는 목록 이동)을 제공해야 한다(MUST).

#### Scenario: 존재하지 않는 게시물 ID 접근

- **WHEN** 사용자가 존재하지 않는 게시물 ID로 `/posts/[id]`에 접근한다
- **THEN** 시스템은 게시물을 찾을 수 없다는 상태를 표시한다

#### Scenario: 일시적 조회 실패 발생

- **WHEN** 네트워크 오류 등 일시적 오류로 단건 조회가 실패한다
- **THEN** 시스템은 재시도 동작을 포함한 오류 상태를 표시한다
